# Supafilm Models

## Français — À quoi sert ce dépôt ?

Ce dépôt est destiné à distribuer les modèles d’upscaling associés à Supafilm Remaster. Le README indique que des bundles peuvent consulter le manifeste `supafilm_manifest.json` sur la release `latest` pour vérifier les mises à jour.

### Pourquoi l’utiliser ?

Un manifeste et des versions publiées permettent à l’application de savoir quel bundle est le plus récent et d’automatiser la mise à jour, au lieu de demander à chaque utilisateur de rechercher les fichiers manuellement.

### Exemple d’utilisation

Un client Supafilm configuré peut lire le manifeste de la release `latest`, comparer la version annoncée avec celle installée, puis proposer ou télécharger une mise à jour.

**État constaté :** à la date de cette révision, la branche contient uniquement ce README ; aucun manifeste ni modèle n’est présent dans les fichiers du dépôt. Il s’agit donc actuellement d’une page de présentation, pas d’un catalogue de modèles utilisable tel quel.

## English — What is this repository for?

This repository is intended to distribute upscaling models associated with Supafilm Remaster. The README says that bundles can check the `supafilm_manifest.json` manifest on the `latest` release to look for updates.

### Why use it?

A versioned manifest lets the application identify the current bundle and automate update checks instead of asking users to find files manually.

### Example

A configured Supafilm client can read the manifest from the `latest` release, compare the announced version with its installed version, and offer or download an update.

**Current status:** at the time of this review, the repository branch contains only this README; no manifest or model files are present. It is currently an overview page, not a usable model catalogue on its own.
